Gemini API Integration

This project integrates Google's Gemini API for generating text responses based on user prompts.

🚀 Features

Fetch AI-generated responses using the Gemini API

Secure API key storage using .env

Simple UI for user interaction (if using React)

📌 Prerequisites

Before setting up the project, make sure you have:

Node.js (v16+ recommended)

npm or yarn installed

A Google AI Studio API Key (Get it here)
